# 概念

LangChain 是一个专门用于开发由**大型语言模型（LLM，比如 GPT、文心一言等）驱动**的应用程序的开源框架。它就像是连接强大 AI 模型与现实世界的一座桥梁，帮助你轻松地构建出功能丰富、可交互的 AI 应用

> 可以把 LLM 看作是拥有强大智慧但需要"武器"和"指令"的"大脑"-。LangChain 的作用就是提供这些武器（工具）和指令集（标准流程），让这个"大脑"能够真正行动起来，解决实际问题。

# 快速上手

## 环境准备

LangChain.js 要求 **Node.js 20+**（推荐 LTS 版本）。为什么需要这么高的版本？因为 LangChain.js 大量使用了现代 JavaScript 特性（如 ES Modules、Top-level await），这些特性在旧版本中支持不完善。

## 安装核心包

```
npm i langchain
```



##  编写入门程序

```js
import { ChatOpenAI } from "@langchain/openai";

const apiKey = '你的API Key'; // 你的API Key， 正常应该把API Key放到环境变量中（避免泄漏）， 这里为了方便，直接写在代码中。

// 创建 LLM 实例（使用 DeepSeek作为例子）
const llm = new ChatOpenAI({
    modelName: "deepseek-v4-flash",          // 填写你需要使用的模型名称
    configuration: {
        baseURL: "https://api.deepseek.com/v1",  // 填写你需要使用的API Base URL
    },
    apiKey: apiKey,             
    temperature: 0.7,              // 温度参数，控制生成文本的随机性
});

// 直接调用（异步）
async function main() {
    // invoke 可以接收字符串或消息数组
    const response = await llm.invoke("你好，请介绍一下你自己");
    console.log(response.content);
}

main().catch(console.error);
```



## 运行程序

```
node ./index.js
```
